# Home Dashboard
A dashboard for all your needs in one place no download website


## Overview
Omnitool is a fast, lightweight and bloatware-free web application built with HTML5, CSS, Javascript for everyday tasks. It offers a suite of mini uttilies including a pocket calculator, a proportion calculator, a focus timer, age finder and more all in one central website for all your needs. 

## Features
- Pocket calculator
- Proportion finder
- Life tools and Ambient Converters
- Focus Pod/Focus timer
- calculator
- presets options
- temperature studio
